`Requistos minímos:`


Navegador Web: Chrome, Edge, Firefox o Brave (con soporte activo para WebGL 2.0 y la MediaRecorder API para guardar en WebM).

Procesador (CPU): Dual-Core a 2.0 GHz o superior (para calcular la física de las animaciones procedurales).

Memoria RAM: 2 GB disponibles para el navegador (para alojar búferes de texturas y fotogramas).

Tarjeta Gráfica (GPU): Gráficos integrados o dedicados compatibles con WebGL / OpenGL ES 3.0 (Intel HD Graphics 4000, AMD Radeon Vega 3 o superior).

Pantalla: Resolución de 1280×720 (necesaria para visualizar cómodamente el canvas y el editor fotograma a fotograma).

Almacenamiento: ~100 MB libres para la caché de texturas y renderizado de video local.

Recuerda que si quieres grabar un video lo recomendable es grabar un video que grabar la WEBM presionando Windows + Shift + Esc o Windows + Shift + R y en mac Comando + Shift + 5 y lo mismo si quieres guardar el proyecto, lo recomendable es exportar JSON y tomar captura de pantalla
