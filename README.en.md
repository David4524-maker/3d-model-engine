`Minimum requirements:`

Web Browser: Chrome, Edge, Firefox, or Brave (with active support for WebGL 2.0 and the MediaRecorder API for saving in WebM format).

Processor (CPU): Dual-Core at 2.0 GHz or higher (to calculate physics for procedural animations).

RAM: 2 GB available for the browser (to host texture and frame buffers).

Graphics Card (GPU): Integrated or dedicated graphics compatible with WebGL / OpenGL ES 3.0 (Intel HD Graphics 4000, AMD Radeon Vega 3, or higher).

Display: 1280×720 resolution (necessary for comfortable viewing of the canvas and the frame-by-frame editor).

Storage: ~100 MB of free space for the texture cache and local video rendering.

Note: If you wish to record a video, it is recommended to do so externally by pressing Windows + Alt + R (on Windows) or Command + Shift + 5 (on Mac). Similarly, to safely save your project, it is recommended to export the JSON file and take a screenshot.
